# [ VOID SOCIETY ] - HID Pentesting Tool

**Developer:** DAVLOPAR MD.FARID RANA  

An advanced Android penetration testing and HID (Human Interface Device) script tool created under the **VOID SOCIETY** banner. Designed for cybersecurity researchers and ethical hackers to test, analyze, and run automated HID payloads.

---

## 🚀 Features

* **System Status Check:** Real-time monitoring of device Root Status and Kernel Status.
* **HID Script Payload:** Create, save, and execute custom HID scripts to send automated commands to target systems.
* **Gadget Setup & Cleanup:** Easy configuration and cleanup options for HID gadgets.
* **Terminal Logs:** Built-in scrollable real-time terminal output viewer.
* **Cyberpunk UI Design:** Dark theme (`#0A0A0C`) with striking accent colors (`#FF3366`) and monospace typography.
